# Developer Portfolio

A professional, high-performance portfolio website built with Next.js 15, TypeScript, and Tailwind CSS. Designed for developers who want a sleek, modern online presence with zero-code configuration.

## Features

- **Next.js 15 & TypeScript**: Built on the latest Next.js version for optimal performance and developer experience.
- **Tailwind CSS**: Modern styling with a customized design system and dark mode support.
- **Configuration-Driven**: Update your entire portfolio by editing a single TypeScript file.
- **Blog System**: Integrated blog platform with support for HTML content and reading time estimation.
- **Project Showcase**: Accordion-style project list with interactive hover previews and technology tags.
- **GitHub Activity**: Real-time contribution heatmap fetched directly from the GitHub API.
- **Command Palette**: Spotlight-style search (Ctrl+K) for quick keyboard-driven navigation.
- **Interactive Elements**: Custom animated cursor and scroll progress indicator.
- **Mobile Responsive**: Fully optimized for all screen sizes and devices.
- **SEO Optimized**: Dynamic metadata, title tags, and favicon management.

## Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (v18.0.0 or higher)
- npm, yarn, or pnpm

## Development

To run the project locally in development mode:

